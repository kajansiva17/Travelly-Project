# Travelly project rules

Before each task, read:

1. `docs/00-READ-FIRST/Travelly_NBP_Codex_Context.md`
2. The latest relevant delivery report
3. Only the relevant Final Decisions, module contract, API contract and data dictionary

Do not read the full ZIP, all historical chats or unrelated modules unless the requested task specifically requires them.

Treat the latest approved Final Decisions and module contracts as authoritative.

Do not invent business rules.
Do not create an extra application table without approval.
Do not expose private documents, audit history, storage keys, contact details, vehicle plates or precise private locations.

For every task:

- Work on one bounded feature or bug at a time.
- Preserve completed work.
- If a business decision is missing, stop that dependent part and ask one focused question.
- Run only relevant tests.
- Finish with completed scope, deferred scope, changed files, tests, blockers and next dependency.
- Update the relevant delivery report and the NBP context file after approved decisions or completed work.
